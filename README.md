# C@T · HCI presentation

Scroll-through presentation for C@T, the scam-checking email companion for older adults (UCD HCI group project).

- Live app: https://c-t-sandy.vercel.app/
- App source: https://github.com/Shucrates/c-t

## Presenting

Open the site and use the arrow keys, space or scroll to move between slides. Press **F** for full screen. Demo videos play on a loop automatically.

## Structure

- `index.html` — the whole deck (styles, fonts, images and script inline)
- `videos/` — demo recordings, H.264 MP4

Static site, no build step. Deployed on Vercel.
